Theming

CSS variables drive every color, radius and animation — identical to shadcn/ui.

init writes a shadcn-aurelia.css next to your Tailwind stylesheet. It has three parts: the color variables (light values on :root, dark values on .dark), an @theme inline block that maps those variables to Tailwind utilities (bg-background, text-muted-foreground, …), and a base layer with focus/border defaults plus the data-state animations.

The variable contract

Colors come in background/foreground pairs, in oklch: 

:root {
  --radius: 0.625rem;
  --background: oklch(1 0 0);
  --foreground: oklch(0.141 0.005 285.823);
  --primary: oklch(0.21 0.006 285.885);
  --primary-foreground: oklch(0.985 0 0);
  --secondary: oklch(0.967 0.001 286.375);
  --muted: oklch(0.967 0.001 286.375);
  --muted-foreground: oklch(0.552 0.016 285.938);
  --accent: oklch(0.967 0.001 286.375);
  --destructive: oklch(0.577 0.245 27.325);
  --border: oklch(0.92 0.004 286.32);
  --input: oklch(0.92 0.004 286.32);
  --ring: oklch(0.705 0.015 286.067);
  /* … card, popover, chart-1…5, sidebar-* */
}

.dark {
  --background: oklch(0.141 0.005 285.823);
  --foreground: oklch(0.985 0 0);
  /* … */
}
VariableUsed for
--background / --foregroundpage background and default text
--card, --popoversurface colors (+ matching -foreground)
--primary, --secondary, --accent, --mutedcomponent variants (+ -foreground)
--destructiveerrors and destructive actions
--border, --input, --ringborders, form control borders, focus rings
--chart-1 … --chart-5chart series palette
--sidebar-*the sidebar component's own surface scale
--radiusbase radius; rounded-sm/md/lg/xl derive from it

Customizing

Because the file is copied into your project, theming is just editing CSS. Change --primary, tweak --radius, or paste a whole palette from the shadcn/ui theme generator — the variable names are identical, so upstream themes work as-is.

Adding your own semantic color follows the same pattern:

:root { --warning: oklch(0.84 0.16 84); --warning-foreground: oklch(0.28 0.07 46); }
.dark { --warning: oklch(0.41 0.11 46); --warning-foreground: oklch(0.99 0.02 95); }

@theme inline {
  --color-warning: var(--warning);
  --color-warning-foreground: var(--warning-foreground);
}

…which makes bg-warning and text-warning-foreground available everywhere.

Charts

The chart container resolves var(…) references to concrete colors before handing them to the canvas, and re-renders when the dark class on <html> changes — so chart colors follow your theme automatically. See Chart.
