CLI

Reference for the shadcn-aurelia command line interface.

init

Configures an existing Aurelia 2 + Vite + Tailwind v4 project: runs preflight checks, writes components.json, downloads the theme stylesheet as shadcn-aurelia.css next to your Tailwind entry css, and adds the @import for it. 

npx shadcn-aurelia init [options]
Option Default Description
-c, --cwd <path> . working directory
-r, --registry <url|dir> https://shadcn-aurelia.com/r registry base — an http(s) URL or a local directory
-s, --style <name> default registry style
-p, --prefix <prefix> ui custom element prefix (<ui-button> → <acme-button>)
-b, --base-color <color> zinc base color palette
--css <path> auto-detected stylesheet containing @import "tailwindcss"
-f, --force false overwrite an existing components.json

add

Adds components to your project. Resolves transitive registry dependencies (adding dialog pulls in cn, and sheet pulls in dialog), rewrites import aliases and the element prefix to match your components.json, and installs missing npm dependencies with your detected package manager (pnpm, npm, yarn or bun — detection walks up parent directories, so workspaces work). 

npx shadcn-aurelia add button dialog form [options]
Option Default Description
-c, --cwd <path> . working directory
-o, --overwrite false overwrite existing files (default: skip files that already exist)
--no-install — skip npm dependency installation

diff

Compares your local copies against the registry (after applying the same alias/prefix transforms) and prints a unified diff per changed file — useful to review upstream changes before re-adding with --overwrite, or to see what you customized. 

npx shadcn-aurelia diff            # all installed components
npx shadcn-aurelia diff button     # just one

build

For registry authors: validates a registry.json manifest and emits the JSON artifacts (index.json + one file per item) that init/add consume. Point --registry of another project at the output directory to test locally. 

npx shadcn-aurelia build [options]
Option Default Description
-c, --cwd <path> . source root the manifest's file paths resolve against
-r, --registry-file <path> registry.json registry manifest
-o, --output <dir> public/r output directory
-s, --style <name> default style name for the output layout

Using a different registry

The registry URL is stored in components.json at init time. Point it at a self-hosted registry (any static file server) or a local directory during development: 

npx shadcn-aurelia init --registry ../my-registry/public/r
