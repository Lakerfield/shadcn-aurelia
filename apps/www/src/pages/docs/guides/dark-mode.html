Dark Mode

Class-based dark mode, toggled on the <html> element.

The theme stylesheet defines a custom variant so that Tailwind's dark: utilities — and the .dark { … } variable overrides — activate whenever an ancestor has the dark class: 

@custom-variant dark (&:is(.dark *));

That means dark mode is a single class on document.documentElement. No component needs to know about it; every color routes through the CSS variables.

A theme toggle

A minimal toggle component that persists the choice:

// theme-toggle.ts
export class ThemeToggle {
  isDark = document.documentElement.classList.contains('dark')

  toggle(): void {
    this.isDark = !this.isDark
    document.documentElement.classList.toggle('dark', this.isDark)
    localStorage.setItem('theme', this.isDark ? 'dark' : 'light')
  }
}
<!-- theme-toggle.html -->
<button click.trigger="toggle()" aria-label="Toggle theme">
  \${isDark ? '🌙' : '☀️'}
</button>

Avoiding the flash

Apply the saved (or OS-preferred) theme before Aurelia boots, with an inline script in index.html's <head>: 

<script>
  const t = localStorage.getItem('theme')
  if (t === 'dark' || (!t && matchMedia('(prefers-color-scheme: dark)').matches)) {
    document.documentElement.classList.add('dark')
  }
</script>

Portalled content

Overlays (dialogs, menus, tooltips) render under document.body. Because the variables live on :root and the variant matches any .dark ancestor including <html>, portalled content themes correctly with no extra wiring.
