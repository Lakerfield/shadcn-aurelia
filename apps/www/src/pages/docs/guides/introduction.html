Introduction

Beautifully designed components for Aurelia 2. Accessible. Customizable. Open Source.

shadcn-aurelia is a faithful port of shadcn/ui to Aurelia 2. It follows the same philosophy: this is not a component library you install from npm. It is a collection of re-usable components that you copy into your project via a CLI and a registry — and then own outright.

Why copy-paste?

  • Open code. The component source lives in your repo. Change anything — markup, classes, behavior.
  • No API treadmill. There is no wrapper API between you and the component; you edit the component itself.
  • Composition. Components share a small set of conventions (data-slot attributes, cn(), CVA variants) so they compose predictably.
  • Beautiful defaults. Styles are ported 1:1 from shadcn/ui, on Tailwind CSS v4 with the same CSS-variable theming contract.

How it works

Components are distributed through a registry at https://shadcn-aurelia.com/r. The shadcn-aurelia CLI reads that registry, resolves dependencies, rewrites import aliases and element prefixes to match your project, and writes the files into your source tree: 

npx shadcn-aurelia init
npx shadcn-aurelia add button dialog form

Interactive behavior (menus, dialogs, comboboxes, date pickers …) is powered by Zag.js state machines, wrapped behind a stable facade in @shadcn-aurelia/primitives. Your copied components only import from that facade, so engine internals can evolve without touching your code.
